>
> `Python` `Pandas` `Prophet` `SARIMAX` `XGBoost` `Time-Series Forecasting`

### 💰 Finance AI
> RAG-powered financial assistant offering secure, chat-based financial guidance, with personalized conversation memory, secure backend authentication, and a React frontend integrated with FastAPI.
>
> `FastAPI` `RAG` `Python` `React`

### 🧠 ChillBot — AI Mental Health Support Chatbot
> Flask backend (built as part of a 4-member hackathon team) for an AI mental health support chatbot for students, powered by the Gemini Flash 2.0 API for emotion-based responses. Includes a daily planner with streak tracking, crisis support, and relaxation-technique recommendations.
>
> `Python` `Flask` `Streamlit` `Gemini API`
